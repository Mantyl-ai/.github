# Client Project Conventions

## Repo Naming

All client repos follow this pattern:

```
client-{company}-{project}
```

Examples:
- `client-acme-lead-scoring`
- `client-techcorp-outbound-agent`
- `client-startup-crm-integration`

## Visibility

All client repos are **private** by default. Never make client work public without written approval.

## Workflow

1. Create a new repo from the `client-project-template` template
2. Name it following the convention above
3. Build the project
4. When complete, follow `docs/HANDOFF.md` for delivery

## Status Tracking

Use these status badges in the repo README:

- 🟢 **Delivered** — Project handed off to client
- 🟡 **In Progress** — Active development
- 🔴 **On Hold** — Paused, waiting on client
- ⚪ **Archived** — Completed and archived
